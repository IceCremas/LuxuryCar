# LUXURY.CAR — Luxury Car Booking Service

> Разработка специализированного веб-сервиса для бронирования автомобилей класса люкс.
> **Автор:** Файзуллозода Фатхиддин  
> **Группа:** 01-23 ИСИП ОФ 9

---

## 📌 Актуальность проекта

Рынок каршеринга и аренды автомобилей активно растет, однако **сегмент премиальных и люксовых автомобилей** остается недостаточно покрытым качественными цифровыми решениями.

Существующие платформы (агрегаторы аренды) либо не специализируются на люксе, либо предлагают устаревший интерфейс и сложный процесс бронирования.

### Проблемы клиентов:
- Отсутствие прозрачного ценообразования.
- Необходимость длительного согласования по телефону.
- Дефицит визуальной информации об автомобиле.

### Решение:
Создание **LUXURY.CAR** — веб-сервиса, который решает эти проблемы и может быть использован как дипломный проект с возможностью коммерческого внедрения.

## 🎯 Целевая аудитория

| Категория | Описание |
|-----------|----------|
| **Состоятельные частные лица** | Бизнесмены, топ-менеджеры, владельцы компаний (30–55 лет), ценящие время и комфорт. |
| **Туристы и путешественники** | Люди, приезжающие в другой город/страну и желающие арендовать престижный автомобиль на несколько дней. |
| **Корпоративные клиенты** | Компании, которым требуется аренда люксовых авто для встреч, переговоров, трансфера VIP-гостей. |

---

## ⚙️ Функциональные возможности

### Для всех пользователей:
- Просмотр каталога автомобилей с фильтрацией по маделей автомобилов .
- Детальная карточка автомобиля.
- Бронирование  указанием имени и контактных данных.

### Для администратора (в перспективе):
- Добавление редактирование автомобилей.
- Управление бронированиями.
